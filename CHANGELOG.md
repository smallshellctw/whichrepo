## [0.1.0] - 2026-09-22

### Added

- Local-first task routing for polyrepos, monorepos, and microservices.
- Evidence-backed CLI, Dashboard, stdio MCP server, and Codex skill.
- Runtime-free macOS, Windows, and Linux binaries for amd64 and arm64.
- Language-aware discovery and dependency extraction for Go, JavaScript/TypeScript, Python, Java, Rust, .NET, PHP, and Ruby.
- Pure-Go Tree-sitter syntax evidence without CGO.
- Layered, schema-backed workspace configuration with visible defaults.
- Automated Codex, Claude Code, and Cursor MCP setup.
- Optional Jev decision providers with local fallback.
- Reproducible 100-task mixed-language benchmark.
