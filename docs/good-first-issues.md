# Good first contributions

These bounded improvements are suitable for first-time contributors:

- Add a manifest fixture for an existing language analyzer.
- Improve one troubleshooting message with a reproducible test.
- Add a public, generic benchmark task that exposes a real ranking edge case.
- Add shell completion generation for one supported shell.
- Add a translated integration guide while keeping commands identical.
- Improve keyboard or high-zoom behavior in the Dashboard.
- Add validation for one configuration edge case.

Before starting, search existing issues and comment on the one you want to take. Never use private repositories, customer tasks, credentials, or internal service names in fixtures.
