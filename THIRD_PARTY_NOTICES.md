# Third-party notices

WhichRepo includes open-source dependencies recorded in `go.mod` and `web/package-lock.json`.

The syntax analysis layer uses the MIT-licensed [`gotreesitter`](https://github.com/odvcencio/gotreesitter) pure-Go Tree-sitter runtime and selected upstream grammar artifacts for Go, JavaScript, TypeScript/TSX, Python, Java, Rust, C#, PHP, and Ruby. Grammar source revisions and licenses are maintained by the dependency's language lock and embedded metadata.

Release builds include only the selected grammar subset. Dependency licenses remain with their respective copyright holders.
