# Contributing

Thanks for helping improve WhichRepo.

1. Open an issue before a large behavior or interface change.
2. Keep the local-first privacy boundary intact.
3. Add tests for discovery, routing, provider, or protocol changes.
4. Run `make test`, `make web`, and `go vet ./...` before opening a pull request.
5. Do not include private repositories, customer data, credentials, or unreproducible benchmark claims.

Small documentation fixes and focused bug fixes are welcome without an issue.
